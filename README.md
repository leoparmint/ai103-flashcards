# AI-103 flashcards

Study deck for Microsoft exam AI-103, *Developing AI Apps and Agents on Azure*.

- 401 flashcards across every exam area: multiple choice, with an explanation for each wrong option
- Fill-in-the-function cards built from Microsoft sample code
- Practice questions in the exam's formats, including case studies

Everything is in `index.html`, a single self-contained page. Progress is saved in your browser only.

Cards and questions cite the Microsoft Learn pages they come from. Practice questions are original and are not real exam questions.
